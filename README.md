# Avalanche Consensus Experiment

A lightweight GitHub Pages project built for the Team1 Turkey Avalanche content series.

The site visualizes the official Avalanche safety bound:

`P(safety violation) < (1 - αc / k)^β`

Users can adjust `k`, `αp`, `αc`, and `β` to see how the bound and the surrounding intuition change in real time.

## Local preview

Run a static server from the project root:

`python3 -m http.server`

## GitHub Pages

This project is plain `HTML`, `CSS`, and `JavaScript`, so it can be published directly from the repository root with GitHub Pages.
